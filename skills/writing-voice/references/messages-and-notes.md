# Slack, email, and working notes

## 9. Genre playbook (excerpt)

**Working notes** (meeting/interview notes, scratch analysis nobody else has to act on). The one place the rest of this file relaxes: a subject-less, article-less fragment can stand alone as a complete verdict ("high team to team variability"), a concession can ride as a trailing clause instead of getting its own sentence, and a single scare-quoted word ("sloppy") can carry what a full clause would elsewhere. Don't polish these — the compression is the point.

**Slack / email.** Same defaults as the rest of this file — impersonal where the content is a fact or a decision, first person only for a genuine aside — but shorter, and a direct question can open the message instead of a stated claim.
